# Hackathon_Nanobot
This is an potential drug delivery system for cancer made by out team, RRMA.
The project uses Nanobots as a medium to deliver the drugs.
The insides are made of a hydrogel which is non toxic and biocompatible.
The surface has proteins that tells the immune system to ignore bots as a do not eat me signal.
The shape of the nanobot is a hollow cylinder.
The outer body of the Nanobots are made of lipids. Same thing that makes fatty acids and fats.
It uses sonar to make a personalized map of each person's body.
